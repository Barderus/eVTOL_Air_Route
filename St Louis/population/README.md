# St. Louis Population Data

This folder contains:

- `population_data.csv`
  - 2024 ACS five-year B01003 total-population estimates
  - source: [U.S. Census Bureau data table](https://data.census.gov/table/ACSDT5Y2024.B01003?q=B01003&g=040XX00US29,29$1500000)
- `tl_2025_29_bg/`
  - 2025 TIGER/Line Missouri block-group boundaries
  - source: [U.S. Census Bureau TIGER/Line shapefiles](https://www.census.gov/cgi-bin/geo/shapefiles/index.php)
- Illinois population coverage comes from `Chicago/population/`:
  - `population_data.csv`
  - `tl_2025_17_bg/`
